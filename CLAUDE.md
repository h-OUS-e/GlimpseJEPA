# Style Instructions

- use Google Docstrings. Keep them short
- Write short comments to explain confusing lines of code (e.g. # Projecting only the CLS token # Getting the CLS token, etc...)
- When writing comments, avoid bot-like styling. Keep it human:
  - Do not put unnatural spaces and tabs
  - Do not write multiple comment lines unless absolutely impossible to fit idea in one line
  - Always attempt to write the comment in one line. Keep it short but easy to read and understand.
